# Security Policy

## Supported versions

This project is currently maintained on the `main` branch only.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

Report vulnerabilities through GitHub Security Advisories (preferred) or by
contacting the maintainer privately.

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if available)

You should receive an initial response within 5 business days.
